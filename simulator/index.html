毛髪温度 Ts – t 仮定

集中定数の熱収支：C dTs/dt = G(Tair − Ts) − ṁ[L(Ts) + qs(W)]、C = mh(1300 + 4180W)。総括伝熱コンダクタンス G は恒率期に Ts が湿球温度 Twb になるよう較正（Lewis 数 = 1）。qs(W) = q₀e−W/0.11 は結合水の脱着熱。水が蒸発している間は潜熱で冷やされ Ts ≈ Twb、Wc2 以降は蒸発が細り Ts が上昇、乾燥完了後は送風温度まで一気に上がる——論文 §3.2 の SEM で見られたキューティクル熱融着の原因です。

熱損傷の累積

この条件での損傷指標

「変成超過量」= ∫max(0, Ts − Tden(W))dt［K·min］。0 なら一度も変成温度を超えていません。目標含水率に達した時点で送風を止める想定で評価しています。

湿り空気：送風温度と湿球温度・相対湿度

絶対湿度 H 一定の空気を加熱すると相対湿度は急低下し（加熱除湿）、湿球温度はゆっくりしか上がりません。恒率期の毛髪温度は湿球温度に張り付くため、高温送風でも濡れている間は毛髪は比較的低温です。

毛髪の水分収着等温線（GAB 式） 仮定

W = XmCKaw/[(1 − Kaw)(1 − Kaw + CKaw)]、Xm = 0.07, C = 8, K = 0.8（ヒト毛髪の文献値の傾向に合わせた値）。平衡含水率は「空気の相対湿度」で決まり、乾燥のゴール We を与えます（相平衡）。

送風プロファイルの比較

各行を同じ毛束・同じ湿度で計算し、目標含水率に達した時点で送風停止とした比較です。加熱量指数 = ∫(Tair − 25)dt（風量一定とした相対的な電力量の目安）。「高温→Wc2で低温」が、速さと熱損傷の両立を狙う論文 §4.4 の提案です。
