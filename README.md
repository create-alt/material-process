# Forest Boids 3D — 森の競争シミュレーター

単独リスのシミュレーター（元の `index.html`：森の中のリス 1 匹）をベースに作り替えたものです。
**リス・カラス・アカネズミ・カケス・イノシシの 5 種の群れ**が、森に落ちるどんぐりと場所を奪い合います。
この**競争そのもの**をシミュレーションして観測する 3D アプリです。

- Reynolds, C. W. (1987). *Flocks, Herds, and Schools: A Distributed Behavioral Model*. Computer Graphics (SIGGRAPH '87), 21(4), 25–34.
- 水口 毅・右衛門佐 誠・早川 美徳・G. Vásárhelyi・M. Nagy (2017).「飛行する鳥の群れの計測と解析」可視化情報 37(144), 14–19.

## 使い方

`index.html` をブラウザ（Chrome / Edge / Safari / Firefox の最新版）で開くだけです。
three.js を CDN（jsDelivr）から読み込むため、**インターネット接続が必要**です。リスの 3D モデル（glTF）は元版と同じく HTML に埋め込まれています。

| 操作 | 内容 |
| --- | --- |
| 右パネル「シナリオ」 | 共存の森 / リス vs カラス / 凶作 / 豊作 / イノシシの群れ |
| 右パネル「種ごとの設定」 | タブで種を選び、その種の群れ方・競争の形質・代謝などを変える |
| 左パネル | 競争の観測（種の表・個体数の推移・どんぐりの取り分・勝ち負けの表・なわばり地図・群れの構造） |
| 地面をクリック | どんぐりを撒く |
| 動物をクリック | 個体を選択（視野・近傍・行動の要求を表示し、その種を選ぶ） |
| 🎯 / 🦅 / 💥 | 選んだ種の目的地 / 天敵のタカ / 驚かせて散開 |
| ⏸ / スペースキー | 一時停止。シミュレーション速度は ×1〜×8 |

## 設計: どの種も対等な「群れ」として扱う

すべての動物は**同じ `Agent` クラス**（ボイド）で動きます。種の違いは、パラメータの表 `SPECIES` の数値だけで表します。
見た目（`Body`）と行動（`Agent`）を分けているので、リスも特別扱いされていません。

| 種 | 群れ方 | 1 個体の強さ | 競争の戦略 | 天敵への対応 |
| --- | --- | --- | --- | --- |
| 🐿️ ニホンリス | 中くらいの群れ | 1.0 | 数の力で取り囲んで追い払う（モビング） | 木に登る |
| 🐦‍⬛ ハシブトガラス | ゆるい群れ・飛行中だけ整列 | 3.0 | 広く見渡して飛んで先回り、弱い相手から横取り | 平気 |
| 🐭 アカネズミ | ほとんど群れない | 0.25 | 争わずに譲る。小食で、どんどん増える | 物陰に隠れる |
| 🐦 カケス | 群れで飛ぶ | 1.2 | 群れで騒いで追い払う。どんぐりへの依存度が高い | 飛び去る |
| 🐗 イノシシ | 家族群でまとまる | 12 | 圧倒的な力で押しのける。大食い | 平気 |

### 競争の仕組み

| 競争の種類 | 実装 |
| --- | --- |
| **消費型競争**（早い者勝ち） | 種ごとに、餌を見つける距離・速さ・食べる時間・飛べるかどうかが違う |
| **干渉型競争**（追い払い） | 争いの勝ち負けは**数の力**で決まる。数の力は、半径 1.6 m 以内の同種の強さの合計（数の力で戦う種の場合）。相手より十分強く攻撃的な個体は、餌をめぐって相手を取り囲む。取り囲む側の強さの合計が相手の数の力を超えると、相手はどんぐりを落として退く（飛べる種は森の外へ） |
| **労働寄生**（横取り） | カラスは、自分より数の力が弱い他種が食べているどんぐりを奪う |
| **譲歩と危険の回避** | 自分より強く攻撃的な相手には近づかず、そのそばのどんぐりも避ける（飢えていれば危険を冒す）。ずっと小さな相手は追い払わない |
| **割り込み** | 自分の数の力が十分強ければ、他種が確保したどんぐりを横取りできる |
| **食物の重なり** | 必要なエネルギーのうち、どんぐり以外の食べ物で賄える割合（`otherFood`）が種ごとに違う。重なりが大きい種ほど競争の影響を強く受ける |
| **個体群動態** | 動くと（飛ぶとさらに）エネルギーを使い、どんぐり 1 個で 1 単位補給する。蓄えが尽きると力尽き、十分な蓄えのある成熟個体は子を産む。競争の結果は個体数に表れ、**共存**するか、どれかの種が消える（**競争排除**）か、が観測できる |
| **すみ分け** | 各種は別々の場所から出発し、なわばり地図でどこを誰が占めているかが分かる |

元版のリスの生態（間欠移動、警戒声、木への避難、両手で食べる、毛づくろい）は残しています。
ほかの種にも、それぞれの生態を加えました（ネズミは物陰に隠れる、カケスは飛び去る、イノシシは鼻で掘り返して食べる）。
警戒声は**種を越えて伝わります**（他種の警戒声の盗み聞き）。

## 論文の内容とコードの対応

### Reynolds (1987)

| 論文の概念 | 実装（`index.html` 内） |
| --- | --- |
| **3 つの規則**：Collision Avoidance / Velocity Matching / Flock Centering | `Agent.separation()` / `alignment()` / `cohesion()`（同種の仲間に対して） |
| **加速度要求**と**優先度付き加速度割当** | `Agent.arbitrate()`（加重平均にも切替可） |
| **局所的な知覚**（半径・指数・視野 ≈ 300°） | `Agent.perceive()`。同種は視野内、他種は気配で全方向 |
| **幾何学的飛行**・推進と操舵の分離・バンク | `Agent.locomote()`。鳥は実際に飛び（高度をバネで制御）、旋回でバンクする |
| **障害物回避 steer-to-avoid** | `Agent.steerToAvoid()`（飛行中は幹だけが障害物） |
| **移動衝動** | 🎯 選んだ種の目的地 |
| 障害物は**捕食者**でもよい | 🦅 タカ（`Hawk`）。種ごとに 木に登る / 隠れる / 飛び去る |
| **群れ・群れ・魚群は同じ枠組み**（Other Applications） | 5 種すべてを同じ `Agent` で表し、パラメータだけを変える |
| **再開可能な乱数** | `mulberry32(1987)`（シナリオをリセットすると同じ初期条件） |
| **O(N²) の回避** | `SpatialGrid` |

## 課題の 4 つの集団行動

右パネルで種を選び、「無関係・結合・分離・整列・ボイド」を切り替えると、**その種だけ**の群れ方が変わります。
群れ方の違いが、競争にどう影響するかを観察できます。
「リス vs カラス」で 5 分間動かした例（1 回ずつの結果）:

| リスの群れ方 | カラスがリスに勝った回数 | リスがカラスを追い払った回数 |
| --- | --- | --- |
| ボイド | 10 | 3 |
| 結合 | 28 | 1 |
| 分離（縄張り） | 65 | 0 |

散らばると数の力が落ちて、カラスに横取り・追い払いされやすくなります。
寄り集まるだけ（結合）では向きがそろわず、取り囲んで追い払う動きにはなりにくいようです。

## 実験のヒント

- ブラウザのコンソールから `__SP.crow.dominance = 6` のように種のパラメータ、`__P.acornRate = 10` のように環境を変えられます
- 「どんぐり以外で賄える割合」を 2 種で入れ替えると、勝ち負けが逆転することがあります（食物の重なりと競争排除）
- 「数の力で戦う」を切ると、群れることの利点が消えます
- 「森の外からの移入」を入れると、消えた種が戻ってきて、競争が繰り返されます
