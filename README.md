# 求人パースHub (Job Parser Hub)

企業の採用情報や求人票のテキストをコピペするだけで、**表現の揺らぎ（同義語・記号・見出しフォーマットの違い）を自動吸収**し、構造化して**Excel対応CSV**へエクスポートできるWebアプリケーションです。

---

## 🌟 主な特徴

1. **表現の揺らぎを強力に吸収（内蔵パーサー）**
   - 日本の採用市場・転職サイトで使われる200種類以上の見出し表現、シノニム（同義語）、前置記号（`【】`, `■`, `▼`, `◆`, `●`, `#`, `：` など）を自動認識。
   - 例:
     - **給与**: 「給与」「想定年収」「年収」「月給」「賃金」「報酬」「年俸」「給料」など
     - **勤務地**: 「勤務地」「就業場所」「就業地」「勤務エリア」「所在地」「アクセス」「リモート可否」など
     - **応募資格**: 「応募資格」「必須要件」「対象となる方」「求める人物像」「MUST要件」「必要条件」など
     - **歓迎要件**: 「歓迎スキル」「歓迎要件」「あれば尚可」「WANT要件」「望ましい経験」など
     - **仕事内容**: 「仕事内容」「職務内容」「業務内容」「担当業務」「主な仕事」など
     - **福利厚生**: 「福利厚生」「待遇」「諸手当」「社内制度」など
     - **選考フロー**: 「選考フロー」「選考プロセス」「選考方法」「選考手順」など

2. **Excel完全対応のCSV出力（文字化けゼロ）**
   - 日本語環境のMicrosoft Excelで開いても文字化けしない **UTF-8 BOM (`\uFEFF`)** 付きでCSVを出力。
   - カンマや改行、ダブルクォートを含む項目も標準RFC4180に準拠して自動エスケープ。

3. **テキスト選択スナイパーマッピング機能**
   - コピペした文章の一節をマウスで選択し、「会社名へ」「給与へ」などのボタンを押すだけで、0秒で該当項目にピンポイント反映。見出しのない特殊な文章でも手動修正が極めて快適です。

4. **ローカル完結＆プライバシー安全**
   - すべての処理はブラウザ内部（JavaScript）で完結します。コピペしたデータが外部サーバーへ送信されることはありません。
   - データはブラウザの `LocalStorage` に自動保存されるため、タブを閉じても消えません。

5. **AI解析（Google Gemini API）オプション連携**
   - 通常は無料・オフラインの内蔵パーサーで高速動作しますが、極めて崩れた散文や海外求人などを解析したい場合、Gemini APIキーを設定することでLLMによるゼロショット高精度抽出も可能です。

## 🚀 起動方法

### 方法1: ブラウザで直接開く（一番簡単）
`index.html` をダブルクリックして、Chrome / Edge などのブラウザで開くだけで即座に使用できます。

### 方法2: ローカルWebサーバーで起動
```bash
# Pythonの場合
python -m http.server 8000

# Node.jsの場合
npx serve .
```
ブラウザで `http://localhost:8000` にアクセスしてください。

## 📖 使い方

1. **採用テキストを貼り付け**:
   - 求人票のテキストをコピーし、左側のテキストエリアに貼り付けます。
   - ※画面上部の「ITエンジニア」「企画営業」「自由形式求人」ボタンを押すと、実際の揺らぎサンプルの挙動を試せます。
2. **「項目を自動解析」をクリック**:
   - 内蔵パーサーが自動でセクションを識別し、右側のフォームに項目ごとに振り分けます。
3. **内容を確認・微調整して「リストに追加」**:
   - 修正が必要な箇所があればフォームで直接修正できます。
   - 「リストに追加」を押すと、下部の蓄積テーブルに登録されます。
4. **「CSVエクスポート」をクリック**:
   - 蓄積された求人データをワンクリックでExcel対応CSVとしてダウンロードできます。
   - 「列カスタマイズ」から出力したい項目だけを絞り込むことも可能です。

## 📂 ファイル構成

- `index.html` : アプリケーションのメイン画面
- `css/style.css` : モダンで洗練されたUIスタイルシート
- `js/parser.js` : 表現揺らぎ吸収ヒューリスティック抽出エンジン
- `js/ai-parser.js` : Gemini API連携モジュール（オプショナル）
- `js/samples.js` : 揺らぎ検証用テストデータ
- `js/app.js` : 画面制御、テーブル描画、LocalStorage永続化、CSV出力
