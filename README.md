# 高専コマナビ — 大阪公立大学高専 時間割・単位ナビ

大阪公立大学工業高等専門学校の **2026年度シラバス（本科）** から抽出した 221 科目のデータをもとにした学習支援アプリです。
時間割づくり、成績のつけ方の確認、出席・提出物の記録、単位取得の可能性と成績の見込みまでを 1 つの画面群で扱います。

- ブラウザだけで動きます（HTML / CSS / JavaScript のみ。ビルド・サーバー・外部ライブラリなし）
- データはすべて端末内に保存します（`localStorage`、写真だけ `IndexedDB`）。どこにも送信しません
- 学校の公式ツールではありません。予測は目安です

## 使い方

`index.html` をブラウザで開くだけです（`file://` でも動きます）。

1. 画面上部で **学年** を選ぶ（2年以上は **コース**、4年以上は **応用専門の領域** も）
2. **時間割** で科目をコマへ並べる
3. 毎日の **出席** と **課題・試験** を記録する
4. **成績予測** と **単位・進級** で見通しを確認する

## 機能

| 画面 | できること |
| --- | --- |
| ホーム | 今日の授業と出欠のワンタップ記録、7日以内の締切・試験、注意が必要な科目、授業外学習の目安 |
| 時間割 | 学年×前期/後期ごとの時間割。科目リストからドラッグ＆ドロップ（スマホは科目→コマの順にタップ）、コマ同士の入れ替え、教室・メモ、自作科目（HR など）、通年科目のコピー、印刷 |
| 科目・評価 | 試験の有無（中間／定期）と評価配分の早見表。科目名からシラバス全文（概要・達成目標・授業計画・教科書など）を表示。配分は自分で編集可 |
| 出席 | 日ごとの出欠（出席・欠席・遅刻・早退・公欠・休講）、未記録コマの一括「出席」、補講などの追加記録、科目ごとの欠課数と「あと何コマ休めるか」 |
| 課題・試験 | 課題・小テスト・試験の期限、提出状況、点数、提出物のリンクと写真、メモ。評価項目に紐づけて成績予測へ反映 |
| 成績予測 | 科目ごとの見込み点・評語・単位取得の可能性、可／良／優／秀に届くために残りで必要な得点率、確定成績の入力 |
| 単位・進級 | 進級に必要な累計単位と必修得科目の状況、卒業要件（一般／専門、DP-A〜E、SDGs科目）の進み具合、学年ごとの単位台帳、特別学修の単位、規程の早見 |
| 設定 | コマ数・時刻、遅刻の換算、学年暦と試験期間、ライト／ダーク、バックアップの書き出し・読み込み、全消去 |

## 計算の根拠

学生便覧の「成績評価・学年の課程修了及び卒業の認定等に関する規程」「特別学修規程」にもとづきます。

- **単位取得**: 100点法で 60点以上（秀 90〜／優 80〜／良 70〜／可 60〜）。卒業研究などは合否評価
- **出席**: 総授業時間数の 2/3 以上の出席がない科目は原則 0点。総授業時間数は、履修単位 1単位＝30単位時間、学修単位 1単位＝15単位時間の授業として計算（90分＝2単位時間）
- **進級**: 累計取得単位が 1年 27／2年 62／3年 97／4年 136 以上、かつその学年の必修得科目をすべて取得
- **卒業**: 累計 167単位以上（一般 75・専門 82 以上）、DP-A 21（SDGs科目 5科目以上）、DP-B 39、DP-C 20、DP-D 50、DP-E 16 単位以上
- **特別学修**: 加算の上限 60単位（別表の資格・検定などは 10単位）

### 成績予測の方法

1. 評価項目ごとに、紐づけた課題・試験の得点率を平均します（「未提出」は 0点、手入力の得点率があればそれを優先）。
2. まだ点数のない項目は、これまでの得点率と「想定得点率」（既定 70%）をならした値で補い、見込み点を出します。
3. 未確定の配点が多いほど見込みの幅を広くとり、60点を超える確率を「単位取得の可能性」とします。
4. 欠課が上限を超えた科目は可能性 0% とします。点数の記録が 1つもない科目は判定せず、単位の合計では取得できるものとして数えます。

## データについて

- 出典: [2026年度シラバス（本科）](https://www.omu.ac.jp/ct/syllabus-reg/)（1〜5年の PDF）、[学生便覧](https://www.omu.ac.jp/ct/_media/KOSEN_gakuseibinran-original.pdf)、2026年度 行事予定表（後期）
- `js/data.js` は `tools/build_data.py` が生成します。PDF を `pdftotext -layout` でテキスト化した `y1.txt`〜`y5.txt` を入力にします。

  ```bash
  python3 tools/build_data.py <テキストのあるフォルダ> js/data.js tools/eval_overrides.json
  ```

- 評価配分は【成績評価の方法】の文章から機械的に抽出しています（180 科目）。文章の形が特殊な 30 科目は `tools/eval_overrides.json` に人が読み取った配分を書いています。合否評価の科目と配分の記載がない科目（11 科目）は「総合評価 100%」として扱います。
- 時限の時刻と前期の試験期間はシラバス・便覧に記載がないため、設定画面で入力してください（時刻の初期値は仮の値です）。
- 遅刻・早退の欠課への換算は便覧に明記がないため、既定では換算しません（設定で変更可）。

```
js/main.js              起動とイベント
tools/                  データ生成スクリプト
```
