# 記憶媒体を運ぶロボット — 環境添付型記憶媒体の動的配置シミュレータ

ロボットは地図を持ちません。通路の要所に貼られた記憶装置から「目的地へはどちらへ進むか」を読み書きして作業します。さらに、よく使われる知識を残すために、ロボット自身が記憶媒体を取り外し、必要とされる場所へ運び直します。この論文を、ブラウザで動かして理解するためのシミュレータです。

## 参照した論文

- 梅谷智弘・前泰志・井上健司・新井健生
  **「自律作業ロボット間における知識共有を目指した環境添付型記憶媒体の動的配置」**
  日本ロボット学会誌 20(6), 631–639, 2002.
  [J-STAGE](https://www.jstage.jst.go.jp/article/jrsj1983/20/6/20_6_631/_article/-char/ja)
- PDF: [`paper/Umetani2002_EnvironmentAttachedStorage_JRSJ20-6.pdf`](paper/Umetani2002_EnvironmentAttachedStorage_JRSJ20-6.pdf)（J-STAGE から取得。著作権は著者と日本ロボット学会にあります）

### テーマとの対応

| テーマ | 論文の内容 |
| --- | --- |
| 司令塔を持たない | 地図も知識の集中管理もない。各ロボットは独立に動く |
| 周囲とのみの情報交換 | ロボット同士は直接通信しない。いまいる場所の記憶装置との読み書きだけで知識を共有する（環境を介した間接的な協調） |
| 全体での秩序形成 | 各ロボットが局所的に「知識の有用さ」を評価して記憶媒体を置く・外すことで、環境全体の記憶媒体の分布が作業の割合に合わせて自己組織化する |

## アプリの使い方

`index.html` をブラウザで開くだけで動きます。外部ライブラリは使っていません。PC でもスマートフォンでも見やすいよう、画面幅に合わせて 1 列〜3 列に組み替わります。

| 操作 | 内容 |
| --- | --- |
| 再生・T 進める・最初から | T = 20,000 step（論文の履歴長）単位で進められる |
| 記憶媒体の扱い | 提案手法（動的配置）／一様に固定／知識なし／全知識 |
| 作業割合 | (A) A–H を多く／(B) Q–Y を多く／一様。走らせたまま切り替えて、適応の様子を見る |
| 速度・台数・記憶媒体の総量 | 1〜2,000 step/フレーム、1〜12 台、全知識の 1/6〜すべて |
| フロア図 | 弧が記憶媒体の枚数。青い矢印は、選んだ目的地への知識（進行方向）。＋／− は記憶媒体を置いた／外した場所 |
| 記憶装置パネル | 場所ごとに、全目的地の評価値（C, c̄, γ, 有用さ U）と、保存されている知識 |
| 論文の実験を再現する | 図7・図8・図11 に対応する比較実験を、ブラウザ内で数秒で計算する |

## 実装の要点

- 論文 図5 のフロアモデル（25 か所・38 本の通路と距離）をそのまま使う。
- 知識の有用さ U = γ (c̄ − C)（式1）。C・c̄・γ は式(2)〜(6) で逐次推定する。
- 容量 m を超えたら、最も有用さの小さい知識を消す。評価値は全目的地について残す。
- 記憶媒体の置く・外すは式(7)〜(10) に従う。ロボットは訪れた記憶装置の最小有用さを覚え、その平均 M′ をしきい値にする。運べるのは 1 枚まで（n_rmax = 1）、1 か所の上限は 24 枚。
- 知識の獲得: 出発してから通った各場所への「来た方向」とそのコストを、着いた記憶装置に書き込む（4.2 節）。
- 実験条件: ロボット 4 台、初期配置は各場所 12 枚（全知識の 1/2）、記憶媒体の移動は 1T 後から、5T で作業割合を (A) から (B) に切り替える。

### 論文に書かれていない部分の補い方

- 1 step で距離 1 進む（通路の数字 = かかる step 数）。
- 知識がないときのランダム移動では、来た通路を戻らない（行き止まりは除く）。
- 「5:1」は目的地 1 か所ごとの重みとして扱う。
- 保存できる知識は、これまでの最小コスト以下の経路で得たものだけ。進行方向とコストが常に対応するので、知識をたどっても堂々巡りにならない。
- 「前もって適応させた配置」は、(A) または (B) で 5T 走らせたあと、配置と知識を固定したものとして再現。

### 再現結果（ヘッドレス計算）

| 条件 | 論文（図8 の読み取り, 前 / 後） | 本シミュレータ（前 / 後） |
| --- | --- | --- |
| 提案手法 | 約 900 / 1,050 | 約 1,200 / 1,430 |
| 一様に固定 | 約 650 / 750 | 約 1,020 / 1,020 |
| 知識なし | 約 180 / 200 | 約 200 / 220 |
| 全知識 | 約 1,580 / 1,700 | 約 1,740 / 2,030 |

- 作業達成数の絶対値は論文より大きめに出ます。条件どうしの大小関係は論文と同じです。
- 提案手法は一様配置の 1.2〜1.4 倍で、論文の「約 1.3 倍」に近い値です。
- ロボットの推定 M′ と真の M の比は 1.0 前後でした（論文は 0.8〜1.2）。
- 記憶媒体を増やすほど作業達成数が上がり、どの量でも提案手法が一様配置を上回ります（図11 と同じ傾向）。
