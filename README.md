# Squirrel Boids 3D — 森のリス群れシミュレーター

単独リスのシミュレーター（`index.html` の元版：森の中のリス 1 匹）をベースに、
**複数のリスが森の中で群れとして行動する** 3D シミュレーターに作り替えたものです。
個体の運動は Craig W. Reynolds のボイドモデルに従います。

- Reynolds, C. W. (1987). *Flocks, Herds, and Schools: A Distributed Behavioral Model*. Computer Graphics (SIGGRAPH '87), 21(4), 25–34.
- 水口 毅・右衛門佐 誠・早川 美徳・G. Vásárhelyi・M. Nagy (2017).「飛行する鳥の群れの計測と解析」可視化情報 37(144), 14–19.

## 使い方

`index.html` をブラウザ（Chrome / Edge / Safari / Firefox の最新版）で開くだけです。
three.js を CDN（jsDelivr）から読み込むため、**インターネット接続が必要**です。リスの 3D モデル（glTF）は元版と同じく HTML に埋め込まれています。

| 操作 | 内容 |
| --- | --- |
| 地面をクリック | その場所にどんぐりを投げる（お腹のすいたリスが集まる） |
| リスをクリック | 個体を選択（視野の扇形・分離距離の円・見えている仲間への線・各ルールの加速度要求を表示） |
| ドラッグ / ホイール | 視点の回転 / ズーム |
| 🎯 目的地 → 地面をクリック | 群れ全体の目的地（移動衝動）を設定。もう一度押すと解除 |
| 🦅 天敵 (タカ) | 上空をタカが旋回 → 急降下。リスは警戒声を伝え合い、近くの木に駆け上がって避難 |
| 💥 驚かす | 群れを一斉に散開させる（その後、結合ルールで再集合） |
| 右パネル | 行動モデルのプリセットと全パラメータ |
| 左パネル | 群れの観測指標とグラフ |

## 課題の 4 つの集団行動（右パネルのプリセット）

| プリセット | ボイドの規則 | 現れる行動 |
| --- | --- | --- |
| 🙈 無関係 | 3 規則すべて 0 | 各個体が勝手に歩き回り、立ち止まって採餌する |
| 🤝 結合 | Flock Centering が支配的 | 密集した塊を作るが向きはバラバラ |
| 🛡️ 分離 | Collision Avoidance を広い距離（1.7 m）で | 互いに間隔を取り、縄張りのように一様に散らばる |
| ➡️ 整列 | Velocity Matching が支配的 | 前の個体を追いかけるように同じ向きへ流れる |
| 🐦 ボイド | 3 規則を優先度順に統合 | 間隔を保ちつつ向きをそろえてまとまって移動。障害物で分かれ、再合流する |

ヘッドレスブラウザで各プリセットを 50 秒シミュレーションした平均値（24 匹）：

| プリセット | 局所整列度 | 全体の分極度 φ | 平均最近接距離 | クラスタ数 |
| --- | --- | --- | --- | --- |
| 無関係 | 0.48 | 0.17 | 1.38 m | 4.1 |
| 結合 | 0.20 | 0.18 | **0.24 m** | 1.0 |
| 分離 | 0.58 | 0.23 | **1.85 m** | 8.6 |
| 整列 | **0.96** | 0.70 | 0.76 m | 3.4 |
| ボイド | 0.82 | 0.63 | 0.57 m | **1.3** |

## 論文の内容とコードの対応

### Reynolds (1987)

| 論文の概念 | 実装（`index.html` 内） |
| --- | --- |
| **3 つの規則**：Collision Avoidance / Velocity Matching / Flock Centering | `Squirrel.separation()` / `alignment()` / `cohesion()` |
| 行動は「その方向に加速したい」という**加速度要求**（単位長以下に切り詰め、strength 0〜1 を掛ける） | 各行動が `{x, z}`（大きさ ≤ 1）を返し、`truncate()` で制限 |
| **優先度付き加速度割当**（Prioritized acceleration allocation）：優先度順に足し合わせ、最大加速度を超えたら最後の要求を切り詰める | `Squirrel.arbitrate()`。比較用に「加重平均」方式も切替可能（逆向きの要求が打ち消し合う問題を観察できる） |
| **局所的な知覚**：半径と指数で決まる感度（逆二乗が自然）、鳥の視野 ≈ 300° | `perceive()`（半径・視野角）、`sensitivity()` = (BL/d)^n |
| **幾何学的飛行**：運動量の保存、最大速度、最大加速度、粘性減衰。長さの単位は体長 | `locomote()`、`BL = 0.32 m`。地上の群れ（herd）なので 2 次元に拘束し、地形に沿わせる |
| 推進力と操舵力を分けてモデル化する方が現実的（論文の指摘） | 操舵 = 調停結果、推進 = `speedControl()` による巡航速度の維持 |
| **バンク（Banking）**：横加速度に合わせて体を傾ける | リスは旋回の内側へ体を傾ける（`bank`）、タカは協調旋回でバンク |
| **障害物回避 steer-to-avoid**：進路上の障害物だけを考え、シルエットの端から 1 体長外側の点へ舵を切る | `steerToAvoid()`（木・岩・切り株）。描画用形状と衝突回避用形状（円柱）は別に持つ |
| 領域内に閉じ込められた群れ | 森の境界（半径 9 m）を接線方向に回避 |
| **移動衝動（migratory urge）**：全員共通の目標点・方向 | 🎯 目的地 → `goal` |
| 障害物は**恐怖の対象（捕食者）**でもよい。捕食者で群れの本能が鋭くなる | 🦅 タカ（`Hawk`）。警戒中は結合が 1.5 倍になり、木に逃げ込む |
| **即興の群れ**：初期位置を楕円内でランダムに与える、再開可能な乱数 | `spawnOne()`、`mulberry32(1987)`（リセットすると同じ初期条件） |
| **O(N²) の回避**：位置で「ビン」に振り分ける | `SpatialGrid` |
| 群れは障害物で分裂し、再合流する（central force モデルではできない） | 局所的な結合だけで実現。左パネルのクラスタ数で確認できる |

### 水口ら (2017)

| 論文の内容 | 実装 |
| --- | --- |
| 個体の進行方向を基準にした座標系 (ξ: 前後, η: 左右) での**最近接個体の相対位置の分布**（Fig.2–3） | 左パネル「最近接個体の相対位置 (ξ, η)」のヒートマップ |
| **遅延時間 τ と前後位置 ξ の関係 ⟨ξ⟩ = −⟨V⟩τ**（Fig.4, 7。τ は向きの相互相関が最大になる時間差：Nagy ら 2010） | 左パネル「遅延時間 τ と前後位置 ξ」。最近接ペアごとに C(τ) = ⟨v̂ᵢ(t)·v̂ⱼ(t+τ)⟩ を計算し、回帰の傾きと −⟨V⟩ を比較（ボイドモードで傾き ≈ −0.55 m/s、−⟨V⟩ ≈ −0.74 m/s） |
| 先導する個体と追従する個体の**階層**（Nagy ら 2010） | 個体ごとの先導性 `leadership`。整列では先導性の高い仲間を重視（👑 で切替） |
| 各個体は同時に向きを変えず、先導個体が向きを変えた位置まで来てから向きをそろえる | **反応遅延 τ**：仲間の速度を τ 秒前の履歴から知覚 |
| 相互作用は距離ではなく**何番目に近いか（6〜7 番目まで）**で決まる（Ballerini ら 2008） | 「近傍の決め方」を 距離（計量）／ k 番目まで（位相）で切替、k = 7 |
| 群れの秩序の指標（Vicsek らの自己駆動粒子） | 全体の分極度 φ = \|Σ v̂ᵢ\| / N と、近傍との局所整列度 |

### リスの生態として加えた行動

- **間欠移動**：数歩跳ねては立ち止まり、匂い嗅ぎ・二足立ちの警戒・周囲の観察をする（取り残されそうになると切り上げる）
- **警戒声の伝播**：タカに最初に気づいた個体（立ち上がって見張っている個体ほど早く気づく）が警戒声を出すと、3.5 m 以内の仲間に反応遅延の後で伝わり、群れを「波」のように伝わる。警戒中は尻尾を激しく振る
- **木への避難**：近くの木の幹を頭から駆け上がり、安全になるとリス特有の**頭を下にした姿勢**で降りてくる
- **採餌**：お腹がすいた個体は近くの空いているどんぐりを確保し、両手で持って食べ、毛づくろいをする

## 元版から引き継いだもの

森の環境（地形・切り株・光の筋・落ち葉・ホタル・4 つの天候プリセット）、リスの 3D モデルと手続き的な骨格リグ・自動スキンウェイト、状態ごとの骨格ポーズ、尻尾のバネ・ダンパ物理、どんぐりの放物線とバウンド、Web Audio による環境音・鳴き声、ガラス調の UI。
単独版の 1 匹分のリグを、メッシュとスキンウェイトは共有したまま個体ごとに骨格を複製し、最大 60 匹まで動かせるようにしています。

## 実験のヒント

- ブラウザのコンソールから `__P` でパラメータを直接変更できます（例：`__P.fov = 120`）
- 視野角を 360° → 120° に狭めると、前方の仲間しか見えなくなります。隊形がどう変わるか観察してみましょう
- 反応遅延 τ を大きくすると、向きの変化が群れの後ろへゆっくり伝わる様子が見えます
- 「加重平均」に切り替えて木に向かって走らせると、回避と結合が打ち消し合って判断が遅れることがあります
